# SCENE — 製品仕様（設計ドラフト v0.1）

**状態:** 基本方針は合意済み。詳細に未決事項があるため、実装時に想像で仕様を補完しない。

## 1. コンセプト

静止画像を並べた「作品」を、ユーザーが制作・公開できる。作者が許可した作品には、他ユーザーが自分の声や利用権のある外部AI音声でアフレコ版を作って公開できる。視聴者は同じ画像作品の異なる演技版を見比べ、**作品**と**音声・演技版**を別々に星で評価できる。

- サービス名: **SCENE（シーン）**
- 主な利用者: 作者 / 演者 / 視聴者。**兼任可能**で、固定ロール強制なし。
- ブランドの入口: 声優志望者の練習・発表、同時に一般層にも開放。
- サービス内でのAI生成は初期スコープ外。**外部AI音声の持ち込みは許可**（利用許諾と表示は必要）。
- 初期収益化なし。広告や有料プランの仕様は作らない。

## 2. 用語・データの境界

| 用語 | 意味 |
|---|---|
| 作品 (work) | 一つの完結した表現。タイトル・説明・画像シーン群・台本を持つ |
| シーン (scene) | 作品内の**一枚の静止画**とそれに対応する台本。**一つのシーンに複数の台詞・ナレーション可** |
| 台詞 (cue) | シーン内の発声内容。順序、任意の話者情報を持つ。視聴画面には表示しない |
| アフレコ版 (dub) | 元の作品を参照し、音声・画像切替の時間情報を持つ再生版 |
| テイク (take) | 演者が編集中に録音した候補。公開対象は演者が採用したものだけ |
| 評価 (rating) | 作品への星評価、またはアフレコ版への星評価。両者を混合しない |

**重要:** 台詞が切り替わっても画像の切替は必須ではない。**音声によって画像表示時間が変わる**ため、シーンの時間情報は原則アフレコ版側に置く。

## 3. 画面とユーザーフロー

### 3.1 トップ

- 新着作品、アフレコ募集中、作品ランキング、アフレコランキングを並べる。
- 総合ランキングを設けない。
- ランキングから作品・アフレコ詳細へ遷移できる。ランキング一覧上で星評価させない。
- UIデザイン: 和紙・木枠などの伝統要素は閲覧面に、明快な現代UIは操作面に使用。

### 3.2 作者の作品制作

1. ログインした作者が作品名・説明文を入力。
2. JPEG/PNG/WebPの静止画像を追加して順番を並べる（動画/GIFは不可）。
3. 各画像シーンに台詞・ナレーションを**複数でも**記入。話者・順番を編集。
4. 作者が**「他ユーザーのアフレコを許可」**を選択（既定OFFを提案）。
5. 保存・プレビューし、**無音のままでも**公開可能。
6. 作品URLを共有できる。

固定の「シリーズ」「第◯話」「時間尺」を強制しない。タイトル・説明欄へ自主的に話数を書ける。説明文からの自動シリーズ抽出は後回し。

### 3.3 視聴

1. ログインなしで作品を開ける。
2. **画像を表示し、台本テキストを画面に出さない（固定OFF）。**
3. アフレコ版を選んだ場合、版ごとのタイミング情報に従って画像と音声を再生。各シーンの長さは演者ごとに異なってよい。
4. 無音版でも鑑賞できる。**無音版の送り方（手動/時間指定）は初期提案が手動で、最終確認事項。**
5. 鑑賞後に作品の星評価、下部のアフレコ一覧で別の音声版の聴き比べと星評価を行う。
6. アフレコ版には話す内容（元台本）が参照できる情報欄を設ける。**視聴中の画像上には重ねない**。

### 3.4 演者のアフレコ

1. アフレコ許可ONの作品を開く。「アフレコする」を選択。
2. **編集開始前のロード画面**で、全画像・台本・必要な編集リソースを取得。編集開始後の巻き戻し・確認を優先する。
3. 画像と台本を見ながら、マイクで録音するか許諾済み音声ファイルを読み込む。
4. 録音した複数テイクを編集**下書き**として保持し、再生・比較して採用を選ぶ。
5. シーンごとの画像表示時間はアフレコ版に関連付け、音声の長さ・間に合わせて調整できる。
6. 演者が公開を選ぶまで**他人から見えない**。
7. 公開時に再度、作者の許可、ログイン状態、素材の権利・形式を検証してアフレコ版を公開する。

**未決:** 一枚ずつ録る方式と、作品全体を連続録音して自分で場面送りする方式の優先順位。どちらも実装前に確定する。**テイク数の固定上限、収録秒数、下書きの保持日数も未確定。**

## 4. 評価・ランキング

- コメント文によるレビューは初期スコープ外。**1〜5の星評価**を想定。
- 作品（work）への評価とアフレコ版（dub）への評価を混ぜない。
- 同一の本人アカウントが同一対象へ繰り返し多重投票できないようにする（変更・取消の許容条件は別途決定）。
- 星の単純平均だけで順位を決めると少数票が過大評価されるため、票数の下限または統計補正を検討する。**具体的な式・しきい値は未確定**。
- トップに**作品ランキング / アフレコランキング**を表示。**総合ランキングなし**。
- 以前検討した「視聴者貢献ランキング」は算定方法が未確定で、実装確定とみなさない。
- 運営レビューを**1〜2か月ごと**に実施する方針。これはランキングの更新間隔とは区別する（ランキング更新頻度は未決）。

## 5. 投稿権限・安全性

| 操作 | 仮のアクセス条件 |
|---|---|
| 作品を見る | 匿名可 |
| アフレコを試す | 匿名可（対応端末のマイク権限を要する） |
| 作品・アフレコを公開 | ログイン＋本人権限 |
| 星評価する | ログイン |
| 他人の作品へ音声を公開 | ログイン＋作品のアフレコ許可ON |
| 他人の作品・音声を削除 | 管理者または適法な権限保持者のみ |

- 作者の許可OFF後は、新規アフレコの公開を停止。
- 既存アフレコ版の維持/停止は作者・演者の権利と公開約款を踏まえて決める。**勝手に一律削除しない**。
- 人間の声とAI生成音声を識別表示し、声優練習評価に混在させない。
- AI音声は実在人物の無断な声真似・権利侵害を禁止。
- 通報、非公開化、削除申立て、異議申立て、必要なログの保護を実装。
- 利用者のアップロード内容を**Public GitHubへ絶対にコミットしない**。

## 6. パフォーマンスの方針

- **閲覧:** 初めの画像を優先表示、続く画像を順次先読み。画像デコード・回線制御は実測で調整。
- **編集:** 全画像と台本の取得完了後に編集開始。ただし**全画像を一度にメモリ展開する必要はない**。
- **画質:** 投稿解像度は任意、表示・保存用にクライアント側で自動調整。最終的な画像上限/圧縮設定は実機試験で確定。
- **音声:** ブラウザのMediaRecorder対応形式を実行時に検査。端末により録音形式が異なる前提で設計。
- **時間制限:** シーン・作品の固定時間上限なし。実装/配信上の容量・帯域の管理は必要。

## 7. MVPと段階開発

**Phase 1 — コア体験**
- 画像・台本で作品作成 / 無音公開 / 匿名視聴
- 自動画像最適化、作品の公開・非公開
- 作者によるアフレコ許可管理

**Phase 2 — アフレコ**
- 編集専用ロード画面、マイク録音、既存音声の持ち込み
- テイク比較・採用、アフレコ版の保存・公開
- 音声と場面切替の同期

**Phase 3 — コミュニティ**
- アカウント・プロフィール、作品/アフレコへの独立星評価
- 独立ランキング、通報と投稿管理

Phase 1でも本番公開前に必要な認証・権限・通報・削除手段の最低限は整える。

## 8. 初期受入テスト

- 無音作品が作成・保存・公開・匿名視聴できる。
- 一枚の静止画に複数の台詞があっても、勝手に絵が切り替わらない。
- 視聴中に台本が表示されない。
- アフレコ許可OFFでは別ユーザーが公開できない（**サーバー側で拒否**）。
- 演者Aと演者Bの同一作品の表示時間が異なっても再生できる。
- 未公開テイクが第三者に見えない。
- 作品評価とアフレコ評価が別々に集計される。
- 端末の録音拒否、回線切断、失敗アップロード時に安全に復旧する。
