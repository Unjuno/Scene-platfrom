## 起動・検証

```bash
cd prototype
npm run check
npm test
cd ..
python scripts/build_standalone.py
python prototype/tests/offline_visual_smoke.py
```

試作アプリ：`prototype/index.html`（ローカル HTTP 配信）
単体オフラインプレビュー：`scene-redesign-preview.html`（ビルドで生成／Gitには含めない）

### 動作上の境界

- ローカル下書きと音声テイクはブラウザのIndexedDBだけに保存。**別端末への公開ではない**。
- ステータス「採用中」は録音練習テイクの**端末内選択**であり、公開アフレコの存在を意味しない。
- 作品の視聴は手動コマ送り。1コマに複数の台詞を設定できるが、視聴中には表示しない。
- Sites上の認証・メディア・DB・星評価・管理APIは、利用可能な実APIが確認されるまで**未接続**。
- 旧来の公開Sitesの既存作品・録音・ランキングを削除せず、まずSitesで稼働ソースと保存方式を確認する。

### 次に行うべき統合作業

1. Sites側から稼働中ソースと依存ライブラリ・バックエンド契約を確認・取得。
2. 既存のコマ送りの回帰テストを作る。
3. 本PRの状態機械とUIを、既存のデータを維持したまま段階的に移植。
4. アカウントA/B/Cで保存→公開→録音→独立星評価を本番同等環境で実証。
5. PC/スマホ実機で検収し、ロールバック・バックアップ・秘密管理を確認してから公開。

**採用前の判断:** レビュー担当は、本PRを本番デプロイと混同してはならない。録音方式（コマ単位か通し録音か）とランキング式は未決事項として残す。
