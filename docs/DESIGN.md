# SCENE ゲーム型UI仕様

コンセプト: Japanese Story Theater × Modern Game UI。画面の中心は静止画が置かれる劇場。左の4つのメニューが鑑賞、制作、収録、ライブラリへつなぐ。

## 色と書体

|用途|色|
|---|---|
|背景|#101A20|
|パネル|#152229 / #1B2B30|
|本文|#F3E8D2|
|金のアクセント|#C6A978|
|録音・エラー|#C75D46|
|木枠|#77543A|

見出しは端末の日本語明朝体、操作はゴシック体。外部フォント通信なし。金属装飾は細い線と角だけに使う。ロゴはコードで作った劇場/クラッパーの記号。サンプル画像はオリジナルのAIイラストで、画像内に文字/UIなし。

## レイアウト

- PC: 固定サイドメニュー + ヘッダー + 中央舞台。ロビーに注目作品、新着/参加募集、独立評価の枠。
- 700px以下: サイドメニューを閉じ、上部に4つの大きな操作。作品は2列、制作はシーン列→画像/台本→設定の縦配置。
- 鑑賞: containで全画像を表示。公開鑑賞面には台詞DOMを描画しない。舞台とHTML操作バーを分離。
- 制作: シーンと台詞の順序は上下ボタンで変更。キーボードでも操作できる。プレビューから戻っても入力を保持。
- 収録: シーン別/通しの切替、テイク比較、音声区分、表示時間。録音状態は色に加えてREC文字で表示。
- Library: 表示名/自己紹介、本人作品/アフレコ、独立した受けた評価数、保存・公開履歴。

## 動きとアクセシビリティ

Canvas 2Dは画像と650msの幕開けのみ。終了後の常時rAFは停止。devicePixelRatioは2まで、ResizeObserverで実表示寸法に追従。端末のprefers-reduced-motionおよび表示設定に従う。Canvas非対応時は同じ画像をHTML imgでcontain表示。パララックスは初版では採用せず、編集/鑑賞操作を優先。

見出し階層、nav/main、スキップリンク、ラベル、フォーカスリング、エラーのrole=alert、通知role=statusを実装。閉じたモバイルメニューはvisibility:hiddenでフォーカス対象から除外。画像説明は作者が編集可能。

## コンポーネント

|ファイル|責務|
|---|---|
|app/components/SceneApp.tsx|ロビー、探索、クエリURLによる画面選択、共通ナビ|
|Stage.tsx|Canvas画像・幕・リサイズ・HTML代替|
|CreatorStudio.tsx|画像最適化、シーン/台詞編集、保存、プレビュー|
|Theater.tsx|手動送り、音声版の共通時計、評価、通報|
|VoiceStudio.tsx|全素材取得、MediaRecorder、音声取込、テイク、タイミング|
|Library.tsx|プロフィール、本人の作品/声/履歴、運営権限時の通報操作|
|lib/domain.ts|入力形式、所有者、音声タイムライン、メディア種別|
|lib/api.ts|D1/R2アダプタと各操作のサーバー認可|
|lib/client.ts|通信、画像最適化、素材の逐次取得|

## サンプルの出自

3枚とも組み込み画像生成ツールで作成、1672×941 WebP。プロンプト概要: 夜の日本の湖畔駅と旅人・月・提灯 → 水面に灯りが映る木橋 → 夜明けの山村の無人駅。手描き2Dゲーム背景、紙の質感、紺黒/青緑/金/銅、文字・UI・透かしなし。元PNGは配信に使用しない。
