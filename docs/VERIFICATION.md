## 4. 可用性・性能の初期仮説（未測定）

**H:** 通常のデスクトップおよび一般的なスマートフォンで、初期画面の表示が著しく遅延せず、無音コマ送りが意図どおり反応する。

**T:** 測定対象HWのCPU/メモリ/OS、ブラウザのバージョン、スロットリング条件、回線、素材枚数・画像サイズ・バッチ、run数をすべて記録。例としてPC Chromium、iOS Safari、Android Chromeの3環境で各10回以上、コールドとウォームを分けて測定。

**D:** LCPの目標は一般的なWeb Vitalsガイドの2.5秒以下を初期目安とするが、本サービスに適切かは素材・回線・利用者で判断。統計量は中央値と範囲で報告。測定が無い段階はUNCERTAIN。

**C:** Canvasが軽くても画像転送、復号、IndexedDB処理、リッチなDOMが遅延原因となる可能性。

**U:** ネットワークの変動、OSのバックグラウンド制限、画像圧縮率、音声コーデック、DOM再描画が主要誤差源。現時点では標本がないため合成標準不確かさの数値評価は不可。サンプル取得後に誤差源別に評価。
