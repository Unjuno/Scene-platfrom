# SCENE — ChatGPT Workへの引き継ぎ

## 1. 開始前の要件

- GitHub URL: https://github.com/Unjuno/Scene-platfrom
- このGitHubリポジトリは仕様とソースコードの正本。
- 公開先候補はChatGPT Sites。実際に利用可能な保存・認証機能を確認するまで実装方式は断定しない。
- 本番の実ユーザー画像・音声・アカウント情報をPublic GitHubへ入れない。

## 2. Workに渡す初回プロンプト

以下をChatGPT Workに渡してください。

```text
GitHubの https://github.com/Unjuno/Scene-platfrom を開き、README.md、
AGENTS.md、docs/DECISIONS.md、docs/PRODUCT_SPEC.md、docs/ARCHITECTURE.md
を読み込んでください。

静止画で制作・公開・アフレコ参加するWebサービス「SCENE」の開発です。
決定ログに書かれた確定事項と提案・未決を混同しないでください。

まずはPhase 1に集中してください。
- 複数の静止画像シーンを並べる
- 各画像に複数の台詞・ナレーションを記入する
- 画像＋台本だけの無音作品をプレビューする
- 視聴画面には台本を重ねない
- 作者がアフレコ許可を設定できるUIを作る
- スマートフォンでも利用しやすい
- デザインは伝統的な紙芝居と現代的な操作性を融合

ChatGPT Sitesでのデータ保存・認証・アップロード・公開の対応状況を先に確認し、
利用できない機能を「対応済み」と言わないでください。

最初に、実装する最小の画面・データ形式・未決事項と検証手順を提示し、
ユーザーの確認後にコードの追加・変更を行ってください。
作業内容はGitHubのPull Requestまたは変更履歴で追えるようにしてください。
```

## 3. 最初の受入確認

- 画像3枚を並べた無音作品を作成できる。
- 1枚目に台詞を2つ設定しても画像は勝手に切り替わらない。
- プレビューで画像だけを表示し、台本は表示しない。
- ブラウザを更新しても保存済み作品が復旧する（ローカル保存だけかサイト保存かを明示）。
- 公開可能と表示する前に、別端末／匿名ブラウザで実際に読めるか確認する。

## 4. 次の段階に進む条件

Phase 1の受入基準が満たされ、作品の保管・公開方法が確定してから、
アフレコ編集、複数テイク、外部音声の持ち込み、録音とシーン切替の同期へ進む。
