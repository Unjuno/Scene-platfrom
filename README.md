# SCENE — 同じ絵、違う声、広がる物語。

SCENE（シーン）は、**静止画像と台本を組み合わせて作品を制作・公開し、作者が許可した作品に他のユーザーがアフレコで参加できる**創作・鑑賞プラットフォームです。

> このリポジトリは開発の正本です。サイトの実装・公開は **ChatGPT Work / ChatGPT Sites** を想定します。現在は設計段階で、サービスはまだ公開されていません。

## 何を作るか

- **つくる:** 静止画像を並べ、シーンごとに台本（複数の台詞・ナレーション可）を設定。**無音のまま公開可能**。
- **演じる:** アフレコを許可した作品に、マイク録音または適法に利用できる音声ファイルで参加。人の録音と外部AI音声は区別。
- **見る:** 画像と選んだ音声版を組み合わせて鑑賞。**視聴中は台本を重ねない**。作品とアフレコを別々に評価。
- **見つける:** 作品ランキング・アフレコランキングをトップに表示。**総合ランキングは設けない**。

「SCENE」は作品を制作・公開・参加・鑑賞する場所であり、画像生成AIや音声生成AIを内蔵することは初期必須要件ではありません。

## デザイン原則

- **伝統と現代の融合:** 鑑賞面には紙芝居の趣、操作面には現代的な明快さ。
- **静止画のみ:** 動画・アニメGIFは対象外。画像はJPEG / PNG / WebPを想定。
- **作品とアフレコの分離:** 画像は作品ごとに保管し、音声・表示時間はアフレコ版ごとに保管。
- **任意の長さ:** シーンにも作品にも固定の時間上限を設けない。
- **許可を尊重:** 作者によるアフレコ許可を作品ごとに管理し、公開時にもサーバー側で検証。
- **収益化は後回し:** 初期版に広告・課金を実装しない。

## 開発の進め方

1. 仕様・未決事項を確認してから画面／データ構造を設計。
2. まず静止画像の作品制作と無音の公開・視聴を完成させる。
3. 作品別アフレコ許可、録音・テイク選択、音声版の公開を追加。
4. アカウント、星評価、ランキング、通報・管理機能を検証する。
5. ChatGPT Sitesの**実際に利用できる認証・保存・配信機能**を確認してから公開する。

## セキュリティ

Publicリポジトリには**パスワード、APIキー、秘密鍵、実ユーザーの音声・個人情報、運用バックアップ**をコミットしないでください。開発に必要なサンプルデータは権利処理されたダミーを使用します。

## 非公開実装版

ゲーム型UIとD1/R2保存を実装したprivate alphaです。最新の実装範囲・制約は [検証記録](docs/QA.md)、[デザイン仕様](docs/DESIGN.md)、[変更履歴](docs/CHANGELOG.md) を参照してください。

```sh
pnpm install --frozen-lockfile
pnpm exec tsc --noEmit
node tests/api.test.mjs
pnpm build
```

Sitesの公開用manifestは `.openai/hosting.json`。DB migrationは `drizzle/`。作品/音声はGitに保存しません。運営権限が必要な場合のみ、サーバー環境変数 `SCENE_MODERATOR_IDS` にSites内の許可するユーザーIDを設定します。値そのものはコミットしません。
